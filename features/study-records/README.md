# 실기 학습 기록

`use-study-records.ts`에서 실기 기출·오답노트·복습 화면의 상태를 공유합니다.
브라우저 저장 키는 `gisa-hub:practical-study:v1`입니다.

- 문항별 답안, 정답 공개 여부, 직접 채점 결과를 저장합니다.
- 틀린 적이 있는 문제는 오답노트에 남고, 이후 맞았다고 채점하면 복습 완료로 바뀝니다.
- 다시 풀기는 이전 답안을 별도로 보관하고 새 답안과 채점 상태를 초기화합니다.
- 마지막으로 조작한 문항은 회차별 이어 풀기 링크로 제공합니다.
- `/past-exams/[examId]/results`에서 회차별 정답·오답·채점 대기·미응시 문항을 확인합니다.
- 결과 화면의 정답률은 채점한 문항만 기준으로 계산하며, 답안을 수정하거나 재채점하면 최신 상태를 반영합니다.
- 브라우저의 다른 탭에서 변경한 기록도 반영합니다.
- 저장이 차단되거나 실패하면 현재 화면의 상태를 유지하고 안내 문구를 표시합니다.

문항마다 최신 결과를 보관하며 전체 응시 이력이나 점수 추이는 저장하지 않습니다.
다른 브라우저·기기와의 동기화는 지원하지 않습니다.

사용자 요청에 따라 테스트·타입 검사·빌드·브라우저 실행은 수행하지 않았습니다.
