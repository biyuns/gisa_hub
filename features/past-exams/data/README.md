# 실기 임시 데이터

- `practical-2026-1.json`: 2026년 1회 실기 임시 데이터, 20문항
- `practical-2026-2.json`: 2026년 2회 실기 임시 데이터, 20문항
- `practical-2025-1.json`: 2025년 1회 실기 임시 데이터, 20문항
- `practical-2025-2.json`: 2025년 2회 실기 임시 데이터, 20문항
- `practical-2025-3.json`: 2025년 3회 실기 임시 데이터, 20문항
- `practical-exams.ts`: 회차 데이터 조회

각 JSON은 연도·회차와 문제·정답·해설을 포함합니다. 해설이 없는 문항은 빈 문자열입니다.

`/past-exams`에서 회차별 **문제 풀어보기**를 선택하면 답안 입력과 정답·해설 확인이 가능합니다.
답안, 직접 채점 결과, 마지막으로 보던 문항을 현재 브라우저에 저장합니다.
‘틀렸어요’로 표시한 문제는 오답노트에 모이며, 복습 후 ‘맞았어요’로 채점하면 복습 완료로 남습니다.
자동 채점과 여러 기기 간 동기화는 제공하지 않습니다.
